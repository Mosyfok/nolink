# NOLINK — настольный мессенджер

NOLINK — исходный проект настольного приложения для Windows, macOS и Linux. Интерфейс работает в Electron, сервер использует Express + Socket.IO, данные сохраняются в SQLite.

## Что уже реализовано

- Регистрация и вход по email и паролю.
- Уникальные имена пользователей.
- Поиск зарегистрированных пользователей.
- Личные и групповые чаты.
- Переписка в реальном времени через Socket.IO.
- Сохранение пользователей, чатов, участников и сообщений в SQLite.
- История последних 100 сообщений в каждом чате.
- Несколько настольных клиентов могут подключаться к одному серверу.

## Требования

Установи Node.js 20 или новее. Для сборки настольного приложения понадобится npm.

## Запуск для разработки на одном компьютере

1. Распакуй архив и открой терминал в папке проекта.
2. Установи зависимости:

   ```bash
   npm install
   ```

3. Создай файл `.env` на основе `.env.example`. Обязательно замени `JWT_SECRET` длинной случайной строкой (не публикуй её).
4. Запусти сервер:

   ```bash
   npm run server
   ```

5. В другом терминале запусти приложение:

   ```bash
   npm start
   ```

Адрес сервера в окне входа по умолчанию — `http://localhost:3030`.

## Как подключить других пользователей через интернет

Чтобы друзья могли общаться из других сетей, сервер должен быть размещён на постоянно работающем компьютере или VPS с публичным адресом.

1. Разверни папку `server` и зависимости проекта на сервере.
2. Настрой `.env`: `PORT`, длинный случайный `JWT_SECRET`, а также `CORS_ORIGIN` при необходимости.
3. Запусти `node server/index.js` или настрой менеджер процессов (например, systemd/PM2).
4. Настрой HTTPS/WSS через reverse proxy (например, Caddy или Nginx) и домен. Не открывай сервер в интернет без HTTPS.
5. Убедись, что папка `server/data` доступна для записи и регулярно резервируется.
6. В настольном приложении на каждом компьютере укажи публичный HTTPS-адрес сервера, например `https://chat.example.com`.

**Важно:** в этом комплекте нет уже оплаченного или развёрнутого публичного сервера. Для реального общения через интернет его нужно отдельно разместить и настроить. Локально приложение запускается на одном компьютере; для внешних пользователей одного `localhost` недостаточно.

## Сборка установщика

```bash
npm run build:win
npm run build:mac
npm run build:linux
```

Сборку каждой платформы лучше выполнять на соответствующей ОС. Результаты появятся в папке `dist`.

## Важные замечания перед публичным запуском

Это стартовая версия, а не готовый к публичной эксплуатации сервис. Перед запуском для широкой аудитории добавь ограничение частоты запросов, подтверждение email, восстановление пароля, модерацию и блокировку пользователей, удаление аккаунта, управление участниками групп, резервное копирование, мониторинг и проверку безопасности. Сейчас в интерфейсе нет сквозного шифрования; сообщения хранятся на сервере в SQLite. Используй HTTPS и не публикуй секреты.
