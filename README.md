# NOLINK — исходный код настольного мессенджера

Проект состоит из Electron-клиента (`desktop/`) и Express + Socket.IO сервера (`server/`).

## Что изменено в этой версии

- NOLINK ID пользователь по-прежнему самостоятельно вводит при регистрации.
- Сервер проверяет уникальность NOLINK ID при регистрации.
- Удалён специальный API-маршрут для изменения ID аккаунта `test`. После регистрации NOLINK ID нельзя изменить через API.
- Добавлен реальный статус активности через Socket.IO. Сервер учитывает несколько одновременных подключений одного пользователя.
- Добавлено окно «Мой профиль»: имя, почта, NOLINK ID (только для просмотра), статус и дата регистрации.
- В личных чатах отображается статус собеседника; в списке чатов у аватара активного собеседника появляется индикатор.

## Требования

- Node.js 20+
- npm
- PostgreSQL (серверный код использует `pg` и `DATABASE_URL`)
- Настроенный Gmail API для отправки кодов подтверждения регистрации

## Настройка сервера

1. Создай PostgreSQL базу данных.
2. Скопируй `.env.example` в `.env`.
3. Заполни `DATABASE_URL` и `JWT_SECRET`. Секрет должен быть случайным и не короче 24 символов.
4. Для подтверждения почты заполни `GMAIL_CLIENT_ID`, `GMAIL_CLIENT_SECRET`, `GMAIL_REFRESH_TOKEN` и `GMAIL_USER`.
5. Установи зависимости и запусти сервер:

   ```bash
   npm install
   npm run server
   ```

Сервер слушает порт `PORT` (по умолчанию 3030). Не публикуй `.env` и не отправляй его в репозитории.

## Настройка адреса сервера в приложении

В `desktop/renderer.js` переменная `base` сейчас указывает на опубликованный адрес NOLINK:

```js
const base = "https://nolink.onrender.com";
```

Для локального тестирования замени адрес на `http://localhost:3030`. Для реального использования через интернет сервер должен быть доступен по HTTPS/WSS.

## Запуск клиента

```bash
npm install
npm start
```

## Сборка Windows

```bash
npm run build:win
```

## Проверки

В этой сборке выполнена проверка синтаксиса Node.js для `server/index.js`, `desktop/renderer.js`, `desktop/main.js` и `desktop/preload.js`.

Полноценный интеграционный запуск не выполнялся: для него нужны рабочие PostgreSQL и Gmail API credentials, а также доступный сервер. Изменения не развёрнуты на `nolink.onrender.com`.
